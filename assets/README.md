# Assets

- `app-icon.png` — application icon.
- `screenshot.png` — hex-grid alkane sketched with the editor.
- `screenshot-start.png` — startup state: Carbon loaded, hexagonal lattice ready.
- `screenshot-sn2.png` — built-in, grid-aligned Sₙ2 mechanism example.
- `screenshot-bond-styles.png` — double-bond junction, horizontal hydrogen-bond
  dashes and bond-aware lone-pair ordering.
- `screenshot-hydrogen-labels.png` — formula labels with implicit hydrogens for
  isolated main-group elements.
- `screenshot-three-bond-pairs.png` — lone pairs nested in the gaps between
  three bond lines.
- `screenshot-element-bond-side.png` — formula labels keeping the element on the
  bond side and moving implicit H to the other side.
- `screenshot-arrow-snap.png` — electron-transfer arrow snapped to a bond middle
  and stopping outside the atom label.

The icon and checkerboard preview texture live in
`src/main/resources/assets/` so they are bundled into the application.
