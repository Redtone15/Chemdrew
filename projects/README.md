# Projects

MolView Studio stores fully editable drawings as `.molview` JSON projects.
`S_N2_Substitution.molview` is a complete, grid-aligned example with:

- atoms and one-hexagon-edge bonds;
- formal and partial charges;
- lone pairs;
- curved electron-pushing arrows;
- a straight reaction arrow; and
- text annotations.

Open it from **File → Open Project…**. The built-in copy lives in
`SampleProjects.java` and is available from **File → Open Example**.
