# Bundled runtime libraries

JavaFX 21 (Windows x64, OpenJFX / GPL v2 + Classpath Exception):

- `javafx-base-21-win.jar`
- `javafx-graphics-21-win.jar`
- `javafx-controls-21-win.jar`

These jars are placed here so the project builds and runs offline with the
included `build.bat` / `run.bat` scripts. On another operating system, replace
them with the corresponding OpenJFX 21 SDK for that platform, or open the
project in an IDE that resolves JavaFX 21.
